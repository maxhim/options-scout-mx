# Falco Scout — движок (Options Scout Engine)

Ежедневный сканер акций и опционов по вотчлисту. Каждый торговый день в последний час сессии
(15:35 по Нью-Йорку, 21:35 по Мадриду) он:

1. Загружает цены, опционные цепочки (OI, объём, IV, дельта) и даты отчётностей.
2. Считает сигналы: тренд, IV30, IV Rank, IV/HV, ожидаемое движение (straddle), Put/Call по OI,
   «стены» OI, max pain, необычный объём (volume > OI), **прирост OI к прошлой сессии** и
   **подтверждённый поток** (вчерашний необычный объём, который закрепился в OI).
3. Ставит скор 0–100 и собирает сделку:
   - **опцион**: контракт до $100 с экспирацией 3–14 дней, где безубыток не дальше ожидаемого движения,
     с нормальной ликвидностью; если одиночный опцион дорогой, предлагает дебетовый спред;
   - **акция**: идея на 1 акцию. Цель — ожидаемое движение за 10 торговых дней по IV30, стоп — половина пути,
     но не ближе 1 ATR; у каждой идеи есть дата выхода.
4. Ведёт журнал: каждая идея записывается автоматически и закрывается по тейку, стопу, экспирации или времени.
   Отдельно считается статистика по каждому сигналу, чтобы было видно, какие из них реально работают.
5. Выпускает бриф: HTML-страницу (`reports/index.html`), `brief.json` и сообщение для Telegram
   (по пятницам с итогами недели).
6. Днём (11:00 и 13:30 по Нью-Йорку) шлёт алерт, только если появилась сильная идея (сила 55+)
   или открытая идея закрылась по тейку/стопу.

Ручной запуск (Actions → daily-brief → Run workflow) по умолчанию в режиме **test**: работает на копии базы
и журнал не трогает. Режимы **brief** и **alert** — настоящие запуски вне расписания.

Все цифры считает код. LLM (по желанию) только пересказывает готовый бриф человеческим языком.

## Быстрый старт

```bash
pip install -r requirements.txt
python -m scout demo --days 45          # прогон на синтетических данных, отчёт в reports/demo/
python -m pytest -q tests
```

### Реальные данные

По умолчанию работает **yfinance**: бесплатно, без ключа и без счёта.

```bash
python -m scout run                      # провайдер yfinance
```

Учтите особенности Yahoo:
- данные с задержкой около 15 минут и неофициальные: Yahoo иногда меняет формат или ограничивает запросы
  (движок повторяет запросы с паузой, сломанный тикер не роняет весь бриф);
- после закрытия рынка bid/ask часто обнуляются, поэтому скан идёт за 25 минут до закрытия;
- мусорную IV у неликвидных контрактов движок пересчитывает из цены сам.

Yahoo иногда блокирует запросы с облачных серверов, в том числе GitHub Actions. Если бриф начнёт приходить
с ошибками загрузки, запускай `python -m scout run --notify` на своём компьютере по расписанию
(cron на Mac/Linux или Планировщик заданий Windows, будни 21:35 по Мадриду) и коммить `data/scout.db`.

Если yfinance начнёт сбоить совсем, можно перейти на Tradier без правок кода: `SCOUT_PROVIDER=tradier` и `TRADIER_TOKEN`.

### Ежедневный автозапуск (бесплатно, GitHub Actions)

1. Залей папку в приватный репозиторий GitHub.
2. Settings → Secrets → Actions (всё по желанию): `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`
   (бот от @BotFather) и `ANTHROPIC_API_KEY` для пересказа.
3. Settings → Pages → Source: **GitHub Actions**. В Variables добавь `SCOUT_REPORT_URL` = адрес страницы.
4. Запусти вручную вкладкой Actions → daily-brief → Run workflow. Дальше он идёт сам по будням в 21:35 по Мадриду.

История (SQLite в `data/scout.db`) коммитится в репозиторий после каждого запуска, поэтому
IV Rank и журнал накапливаются. IV Rank появляется после 20 сессий, до этого используется IV/HV.

## Настройки: `config.yaml`

Вотчлист, депозит и риск на сделку, лимит цены контракта, окно экспираций, фильтры ликвидности,
веса сигналов и даты отчётностей (Tradier их не отдаёт, их можно вписать вручную).

## Как читать сигналы (честно)

- **OI обновляется раз в сутки** (OCC, ранним утром). Дневной снимок показывает OI на закрытие прошлой
  сессии. Поэтому сравнение «вчерашний объём → сегодняшний прирост OI» и есть главная проверка потока.
- Рост OI не говорит, кто покупатель, а кто продавец. Это вероятность, а не факт.
- Дешёвые недельные опционы чаще всего сгорают. Фильтр «безубыток ≤ ожидаемого движения»
  отсекает худшие из них, но не делает их выгодными. Верить стоит только трек-рекорду в журнале
  после 50–100 закрытых идей.
- **Демо-режим генерирует случайный рынок без заложенного преимущества.** Его результаты ничего не значат,
  он только проверяет код.

## Структура

```
scout/providers.py   Tradier, yfinance, демо
scout/signals.py     расчёт сигналов
scout/ideas.py       скоринг, подбор опциона/спреда/акции
scout/journal.py     сопровождение идей и статистика
scout/report.py      HTML-бриф и текст для Telegram
scout/pipeline.py    один ежедневный прогон
scout/storage.py     SQLite
```
